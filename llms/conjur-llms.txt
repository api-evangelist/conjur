# Conjur (CyberArk Secrets Manager)

> Conjur is CyberArk's open-source secrets management platform. It secures secrets used by privileged users and machine identities across CI/CD, cloud, and Kubernetes, using a role-based access control (RBAC) model, policy-as-code, and pluggable cloud-native authenticators (IAM, Azure, GCP, Kubernetes, JWT, OIDC, LDAP). Originally Conjur Inc., acquired by CyberArk, now part of Palo Alto Networks.

## APIs
- [Conjur / Secrets Manager OpenAPI](https://github.com/cyberark/conjur-openapi-spec): OpenAPI 3.1 definition covering authentication, secrets, policies, roles, resources, host factories, public keys, and server status.
